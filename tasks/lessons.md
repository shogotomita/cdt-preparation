# Lessons

## 2026-08-29

- **このリポジトリ外のパスを読まない・コピーしない。** ユーザーが「図は別途この repo に配置」「他フォルダのスキャン不要」と言ったあとも、Desktop 上の過去問フォルダを `ls` / `Read` / `cp` した。禁止されたら即停止し、既に読み取った外部内容も破棄する。素材はチャット添付か `raw/` など **リポジトリ内にユーザーが置いたものだけ** を使う。

- **貸切バス運賃は「図の実数」だけで決めない。** 問51・52で出庫〜帰庫の５時間・104キロを正解にして公式（ウ・ア）と不一致になった。時間制は走行時間に **出庫前・帰庫後の点呼・点検２時間** を加算（→７時間）。キロ制は回送込み合計のあと **10キロ未満の端数を10キロに切上げ**（104→110キロ）。公示運賃の加算・端数ルールを計算過程に必ず入れる。

- **宿泊を伴う貸切バスは点呼点検４時間。** 日帰りは出庫前・帰庫後の計２時間だが、宿泊付きはさらに宿泊到着後・出発前の各１時間を足す（計４）。走行時間は回送込み。回送を別加算しつつ点呼を２時間に抑えると、たまたま正解と同じ数字になって誤式が残る。

- **電話等予約の締結順位は「予約の受付の順位」。** 「承諾の通知の順位」「会員番号等の通知の順位」はひっかけ。成立時期（通信契約＝承諾通知の到達）と混同しない。

- **特別補償の死亡補償金は国内1,500万／海外2,500万。** 1,000万・3,000万は誤り。死亡補償金から控除するのは既払の後遺障害補償金のみ（入院見舞金は合算）。

- **標識には管理者氏名を書く・代表者氏名は書かない。** 「代表者も管理者も書かない」は誤り。
