# 国内旅行業務取扱管理者試験 学習アプリ

## Goal
年度別過去問を1問ずつ解ける学習ページ。正解/不正解のハイライト＋選択肢別・全体解説。
**年度 × 科目（旅行業法 / 約款 / 実務）単位で正答率をトラック**し、各科目60%以上を目指せるようにする。
問題データは JSON テンプレで後から追加可能。
