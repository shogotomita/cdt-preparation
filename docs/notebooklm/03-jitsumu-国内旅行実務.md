# 国内旅行実務 — 過去問解説まとめ

国内旅行業務取扱管理者試験の「国内旅行実務」科目向けの学習素材です。貸切バス運賃、宿泊約款、JR運賃・料金、航空、フェリー、観光地理・世界遺産・モデルコースなど、計算と知識の両面が出ます。計算問題は過程ごと読んでください。

この資料は、国内旅行業務取扱管理者試験の学習用に整理した解説集です。ポッドキャスト化するときは、条文番号の暗唱より「制度の考え方・ひっかけの型・計算の手順」を優先してください。

### 問51

**正解:** ウ（C）

**出題の要旨:** 貸切バスによる運送に関する以下の設問について、選択肢の中から答を１つ選びなさい。

**全体解説:**

【適用ルール】
時間制運賃の算定時間 ＝ 走行時間（出庫から帰庫までの拘束時間。回送・実車・待機・乗降を含む）＋ 出庫前・帰庫後の点呼・点検時間（各１時間、合計２時間）。
走行時間が３時間未満の場合は３時間として計算する下限もあるが、本問の走行時間は５時間のため下限は使わない。
注５どおり、目的地待機は休息期間としない（走行時間から除外しない）。図の※のとおり待機２時間はすでに「４時間」に含まれている。

【計算過程】
1. 走行時間: 出庫 9:00 〜 帰庫 14:00 = ５時間
   （内訳の検算: 回送25分 + 乗降5分 + 実車・待機4時間 + 乗降5分 + 回送25分 = ５時間）
2. 点呼・点検時間: 出庫前１時間 + 帰庫後１時間 = ２時間
3. 時間制運賃の対象時間: ５ + ２ = ７時間
4. よって７時間分 → ウ

【選択肢との対応】
- ア: 走行時間のみ５時間（点検未加算）
- イ: 待機除外の３時間（誤り）
- ウ: ５＋２＝７時間（正解）
- エ: 点検の加算不足などで６時間（誤り）

【学習メモ】
「図の出庫〜帰庫」だけで止めず、公示運賃の点検２時間を必ず足す。待機の二重計上（５＋２待機＝７）と結果が同じになることがあるが、根拠は点検時間の加算である。

**選択肢メモ:**

- × ア（A）: 不正解。出庫〜帰庫の走行時間（５時間）だけを取った誤り。時間制運賃は、これに出庫前・帰庫後の点呼・点検時間（合計２時間）を加える。
- × イ（B）: 不正解。出庫から帰庫までの５時間から待機２時間を除いた３時間だけを取った誤り。待機は休息とせず（注５）、走行時間に含める。また点呼・点検の２時間も加算する。
- ✓ ウ（C）: 正解。走行時間（出庫9:00〜帰庫14:00＝５時間）に、出庫前・帰庫後の点呼・点検時間２時間を加え、７時間となる。
- × エ（D）: 不正解。走行時間５時間に点検を１時間だけ足すなどした中途半端な加算。点呼・点検は出庫前１時間＋帰庫後１時間の合計２時間を加える。

### 問52

**正解:** ア（A）

**出題の要旨:** 貸切バスによる運送に関する以下の設問について、選択肢の中から答を１つ選びなさい。

**全体解説:**

【適用ルール】
キロ制運賃の対象距離は、出庫から帰庫までの走行キロ（回送を含む）。
端数処理: 走行距離の端数について、10キロ未満は10キロに切り上げる。

【計算過程】
1. 回送（出庫→乗車地点）: 11キロ
2. 実車（乗車→降車）: 82キロ
3. 回送（降車地点→帰庫）: 11キロ
4. 合計 11 + 82 + 11 = 104キロ
5. 端数切上げ: 104キロのうち10キロ未満の端数４キロを10キロに切り上げ → 110キロ
6. よって110キロ分のキロ制運賃 → ア

【選択肢との対応】
- ア 110キロ: 回送込み＋端数切上げ（正解）
- イ 82キロ: 実車のみ（誤り）
- ウ 104キロ: 切上げ前の実距離（誤り）
- エ 90キロ: 一部のみ合算（誤り）

【学習メモ】
問51は「走行時間＋点検２時間」、問52は「走行キロ＋10キロ未満切上げ」。実数（５時間・104キロ）で止めるとそれぞれア・ウになり、ひっかけになる。

**選択肢メモ:**

- ✓ ア（A）: 正解。回送を含む走行距離は 11 + 82 + 11 = 104キロ。端数処理により、10キロ未満の端数は10キロに切り上げるため、104キロ → 110キロとなる。
- × イ（B）: 不正解。旅客が実際に乗車する区間（82キロ）のみを取った誤り。回送区間の走行キロもキロ制運賃の対象に含める。
- × ウ（C）: 不正解。回送込みの実距離合計としては正しいが、キロ制運賃では10キロ未満の端数を10キロに切り上げるため、算定距離は110キロになる。
- × エ（D）: 不正解。実車82キロに回送の一部だけを足すなどした中途半端な合算。回送は往復とも含め、そのうえで端数切上げを行う。

### 問53

**正解:** イ（B）

**出題の要旨:** 貸切バスによる運送に関する次の記述のうち、誤っているものはどれか。（注１）「一般貸切旅客自動車運送事業標準運送約款」によるものとする。（注２）貸切バスの運賃は、「一般貸切旅客自動車運送事業の運賃・料金の変更命令について（令和５年８月25日 関東運輸局長公示、令和６年３月１日改正）」によるものとする。

**全体解説:**

【適用ルール】
標準運送約款の違約料（契約責任者都合の解除・車両減少）:
- 配車日の14日前〜８日前: 20％
- 配車日の７日前〜配車日時の24時間前まで: 30％
- 配車日時の24時間前以降: 50％
車両減少は、減少が配車車両数の20％以上のときに、減少台数分について上記率を適用する。

【計算過程（イ）】
1. 減少率: １台／５台＝20％ → 違約料の対象
2. 変更時刻: 配車２時間前 → 「24時間前以降」→ 率50％
3. 違約料: 100,000円 × 50％ = 50,000円
4. 選択肢は100,000円としている → 誤り

【選択肢との対応】
- ア・ウ・エ: 交替運転者料金・航送時間上限８時間・下限額への割引不可はいずれも正しい
- イ: 率を100％と誤認（正しくは50％）→ 設問の正解

【学習メモ】
「２時間前」と書いてあっても率の区分は「24時間前以降＝50％」。100％になる区分はない。車両減少は20％以上が閾値（本問はちょうど20％で対象）。

**選択肢メモ:**

- × ア（A）: 不正解。記述は正しい。交替運転者配置料金は、届け出た下限額以上で算定する。
- ✓ イ（B）: 正解。誤っている記述である。減少は１／５＝20％で違約料の対象となるが、配車日時の24時間前以降の率は50％。正しくは100,000円×50％＝50,000円であり、100,000円とする記述は誤り。
- × ウ（C）: 不正解。記述は正しい。フェリー航送の時間は、時間制運賃の算定上８時間を上限とする。
- × エ（D）: 不正解。記述は正しい。下限額で算定した運賃には、これ以上の割引を適用できない。

### 問54

**正解:** イ（B）

**出題の要旨:** 旅客がフェリーで片道乗船する場合において、旅客が支払うべき運賃の総額について、資料に基づき、正しいものを１つ選びなさい。（注１）「海上運送法第９条第３項の規定に基づく標準運送約款（フェリーを含む一般旅客定期航路事業に関する標準運送約款）」によるものとする。（注２）年齢は乗船日現在とする。（注３）本設問における貸切ジャンボタクシーの車の長さは約5.4ｍ、運転…

**全体解説:**

【適用ルール】
- 自動車航送運賃には、運転手１名が最下等級（本資料では２等船室）に乗船する運賃が含まれる。上位席を使う場合は差額を支払う。
- 自転車などの特殊手荷物運賃には、運送申込人（旅客）の運賃は含まれない。
- 座席を利用しない幼児は旅客運賃不要（本問の１歳）。

【計算過程（イ＝正解）】
1. 自動車航送: 10,000円（運転手の２等1,000円込み）
2. 運転手の指定席差額: 1,800 − 1,000 = 800円
3. 大人４人の指定席: 1,800 × 4 = 7,200円
4. 小児２人の指定席: 900 × 2 = 1,800円
5. 合計 10,000 + 800 + 7,200 + 1,800 = 19,800円

【選択肢との対応】
- ア・ウ: 自転車運賃に旅客運賃を含めない／差し引く誤り
- イ: 運転手は差額、他旅客は満額（正解）
- エ: 運転手分の1,000円を余分に加算

【学習メモ】
「車の運賃に含まれるのは２等の運転手１名だけ」。指定席にするなら差額、自転車は旅客運賃が別途、が頻出。

**選択肢メモ:**

- × ア（A）: 不正解。自転車の特殊手荷物運賃には旅客運賃は含まれない。大人の指定席運賃1,800円を満額加算し、1,200＋1,800＝3,000円が正しい。自動車航送の「２等込み」を準用して1,000円を差し引くのは誤り。
- ✓ イ（B）: 正解。自動車航送運賃10,000円には運転手１名分の２等運賃（1,000円）が含まれる。運転手が指定席を使う場合は差額（1,800−1,000）を加算し、他の大人４人・小児２人分の指定席運賃を加えると19,800円となる。
- × ウ（C）: 不正解。特殊手荷物運賃1,200円に旅客運賃は含まれない。大人の２等運賃1,000円を加え、合計2,200円が正しい。
- × エ（D）: 不正解。自動車航送に含まれるのは運転手の２等分であり、さらに1,000円を足すのは二重計上。運転手の指定席は差額800円の加算が正しい。座席を使わない１歳児は運賃不要。正しくは10,000＋800＋1,800×３＋900＝17,100円。

### 問55

**正解:** エ（D）

**出題の要旨:** 宿泊に関する次の記述のうち、資料に基づき、正しいものを１つ選びなさい。（注）モデル宿泊約款によるものとする。

**全体解説:**

【適用ルール】
- 申込金: 宿泊期間（３日超は３日分）の基本宿泊料を限度
- 違約金: 基本宿泊料に対する比率（サービス料・税は含めない）
- 子供料金（モデル宿泊約款の典型）: 大人に準じる食事・寝具70％、子供用食事・寝具50％、寝具のみ30％
- 入湯税: 本資料では12歳未満免除

【計算過程（エ＝正解）】
1. 基本宿泊料: 30,000 × 50％ = 15,000円
2. サービス料: 15,000 × 10％ = 1,500円
3. 小計: 16,500円
4. 消費税: 16,500 × 10％ = 1,650円
5. 入湯税: ５歳のため０円
6. 合計 16,500 + 1,650 = 18,150円

【選択肢との対応】
- ア: 違約金をサービス料込みで計算（正しくは12,000円）
- イ: 申込金が基本宿泊料限度（120,000円）を超過
- ウ: ホテル１泊の総額が誤り（正しくは50,400円）
- エ: 子供50％＋税・入湯税免除（正解）

【学習メモ】
違約金・申込金のベースは「基本宿泊料」のみ。子供は提供内容で70／50／30％を使い分ける。

**選択肢メモ:**

- × ア（A）: 不正解。違約金の比率は基本宿泊料に対するもの。40,000円×30％＝12,000円が正しい。サービス料込みの44,000円×30％＝13,200円とするのは誤り。
- × イ（B）: 不正解。申込金は宿泊期間の基本宿泊料を限度とする。30,000円×２人×２日＝120,000円が上限。132,000円（税・サービス込み相当）は限度を超える。
- × ウ（C）: 不正解。正しくは基本40,000＋サービス4,000＝44,000、消費税4,400、宿泊税1,000×２＝2,000で合計50,400円。98,800円は過大。
- ✓ エ（D）: 正解。子供用食事・寝具は大人基本宿泊料の50％。15,000＋サービス1,500＝16,500、消費税1,650、入湯税は12歳未満で免除 → 合計18,150円。

### 問56

**正解:** ウ（C）

**出題の要旨:** 旅客鉄道会社（ＪＲ）に関する以下の設問について、選択肢の中から答を１つ選びなさい。

**全体解説:**

【適用ルール】
「分岐駅を通過する列車に乗車する場合の特例」（山科－京都が対象）:
分岐駅（山科）を通過する列車に乗り継ぐため、やむなく最寄り停車駅（京都）まで行き折り返す場合、その折り返し区間の営業キロは運賃計算に含めない。折り返し区間内での途中下車は不可（下車するなら別途運賃）。
本問は京都で改札を出ずに新幹線へ乗り継ぐため、普通乗車券は１枚で連続して計算する。

【計算過程】
1. 在来線側: おごと温泉→京都 20.0キロから、山科→京都 5.5キロを控除 → 14.5キロ（＝おごと温泉→山科相当）
2. 新幹線側: 京都→名古屋 147.6キロから、京都→山科相当 5.5キロを控除 → 142.1キロ（＝山科→名古屋相当）
3. 合計 14.5 + 142.1 = 156.6キロ（式: 20.0−5.5＋147.6−5.5）
4. 普通乗車券１枚 → ウ

【選択肢との対応】
- ア: ２枚かつ新幹線側未控除
- イ: キロは近いが２枚としている
- ウ: 双方控除＋１枚（正解）
- エ: 控除なしの単純合算

【学習メモ】
湖西線→京都折り返し→新幹線東進は「山科問題」の典型。計算上は山科で接続したとみなし、山科－京都を往復分とも運賃キロから外す。特急券・グリーン券は別途。

**選択肢メモ:**

- × ア（A）: 不正解。京都駅で改札を出ずに乗り継ぐため、普通乗車券は１枚で足りる。また新幹線側も山科－京都の5.5キロを控除する。
- × イ（B）: 不正解。各区間のキロ控除の考え方は近いが、改札を出ない連続乗車のため乗車券は２枚ではなく１枚で発券する。
- ✓ ウ（C）: 正解。分岐駅通過の特例により山科－京都（5.5キロ）を在来・新幹線の双方から控除し、おごと温泉→名古屋を156.6キロの普通乗車券１枚とする。
- × エ（D）: 不正解。折り返しとなる山科－京都の営業キロを控除していない。特例を適用すると167.6－5.5－5.5＝156.6キロとなる。

### 問57

**正解:** ウ（C）

**出題の要旨:** 次の経路による行程で大人１人が通常期に乗車するために必要な新幹線の特急料金の額について、資料に基づき、正しいものを選びなさい。（注１）この行程の乗車に必要な乗車券類は、最初の列車の乗車前に購入するものとする。（注２）新山口駅から相生駅まで同日に乗車する。

**全体解説:**

【適用ルール】
- 新幹線の改札を出ると、その駅で特急料金は打ち切り計算になる。
- 改札を出ずに乗り継ぐ場合は、原則として全乗車区間を通しで計算する。
- 「みずほ」指定席と「ひかり」「こだま」等を乗り継ぐ場合は、全区間のひかり・こだま指定席特急料金に、みずほ乗車区間の加算額（みずほ料金−同区間のこだま等指定席料金）を加える。

【行程の整理】
1. 新山口→広島: こだま（普通車指定席）→ その後、広島で改札を出る
2. 広島→岡山: みずほ（普通車指定席）
3. 岡山→相生: 改札を出ずにひかり（普通車自由席）へ乗継

【計算過程】
1. 打ち切り区間（新山口→広島）: こだま指定席 3,060円
2. 通し区間（広島→相生）:
   - ベース: ひかり・こだま指定席 広島−相生 3,930円
   - みずほ加算: 広島−岡山みずほ 3,380 − 同区間こだま指定席 3,060 = 320円
   - 小計 3,930 + 320 = 4,250円
3. 合計 3,060 + 4,250 = 7,310円 → ウ

【選択肢との対応】
- ア: 広島出場を無視した全通し
- イ: 打ち切り駅を岡山と誤認／後半の切り分け誤り
- ウ: 広島で打ち切り＋後半はみずほ加算の通し（正解）
- エ: 岡山でも打ち切った三段計算

【学習メモ】
「改札を出たか否か」が特急料金の区切り。みずほ・のぞみ乗継は「ベース料金＋加算」であり、自由席区間があっても指定席を含む通しでは指定席ベースになる点にも注意（本問資料の式は指定席ベース＋加算）。

**選択肢メモ:**

- × ア（A）: 不正解。広島駅で新幹線の改札を出ているため、新山口〜相生を通しで計算できない。改札出場地点で特急料金は打ち切られる。

- ✓ ウ（C）: 正解。広島で改札出場のため①は新山口〜広島のこだま指定席3,060円。広島以降は改札を出ない乗継のため、広島〜相生のひかり・こだま指定席3,930円にみずほ区間の加算（3,380−3,060）を加えて4,250円。合計7,310円。
